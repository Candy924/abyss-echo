### 為什麼「加到主畫面」的 App 有時不會即時更新？

手機的 PWA（尤其 iOS）會把頁面**凍結在背景**，甚至還原整頁快照，
所以即使伺服器已經是新版，App 也可能繼續跑舊的 JS。針對這點做了四層保險：

1. **每 15 秒輪詢** `version.json`（帶 `?t=` 破快取、`cache: no-store`）
2. **回到前景就檢查**：`visibilitychange` + `pageshow` + `focus` + `online`
3. **自我修復（self-heal）**：比對「畫面上跑的 `GAME_VERSION`」與伺服器 `version.json.version`，
   只要不一致就自動清 Service Worker 快取並重載 —— **每個版本只自動重載一次**，不會迴圈
4. **戰鬥中不打斷**：偵測到更新時若玩家正在打（play / chest / stageclear / talent / pause），
   只把左下角版本號變金色並跳提示，等玩家離開戰鬥或自己按更新才重載

另外更新時會**反註冊 Service Worker + 刪除所有 Cache Storage**（不動 localStorage 存檔），
確保 iOS 不會拿舊快取；畫面元素也都加了 `env(safe-area-inset-*)`，劉海機不會遮住版本號與更新條。

**手動檢查**：直接點左下角的版本號，會顯示「檢查中…」→「已是最新版本」或「找到新版本」。

## 雲端更新（v25 新增）

整套遊戲現在支援「**不換網址、不清進度、玩家自動更新**」：

### 三種更新方式

| 想改什麼 | 改哪個檔案 | 玩家怎麼拿到 |
|---|---|---|
| 平衡數值（武器傷害、敵人血量、難度倍率、天賦、寶箱） | 只改 `content.json` | 下次開啟／回到前景時**自動套用**，不必重新部署程式 |
| 程式、介面、新內容 | 改 `js/`、`style.css`、`index.html` 等 | 玩家會看到「**有新版本**」提示條，按「立即更新」後重載 |
| 緊急修 bug | 同上 + 把 `version.json` 的 `build` +1 | 同上（`build` 變大才會跳提示） |

### 運作原理

- **`version.json`**：版本號。遊戲每 10 分鐘、回到前景、載入時各檢查一次；版本比本機新就顯示更新條。
- **`sw.js`（Service Worker）**：
  - HTML / `version.json` / `content.json` → **network-first**（永遠先拿伺服器最新版）
  - 圖片 / JS / CSS → **stale-while-revalidate**（先用快取秒開，同時背景下載新版）
  - 更新時只清**快取**，`localStorage` 的存檔完全不動
- **`content.json`**：雲端內容包。只允許覆寫「數字/字串」欄位（武器、敵人、天賦、難度、寶箱、全域倍率），不能塞程式碼。
- **`js/updater.js`**：版本檢查、更新提示條、存檔匯出／匯入、F2 熱改面板。
- **`js/content.js`**：抓取並套用內容包（支援 `?content=https://...` 指定外部網址）。

### 存檔安全

- 更新**永遠不會**清除存檔（只刪 Cache Storage）。
- 暫停選單新增「**匯出存檔**」「**匯入存檔**」，換手機或誤清資料都能救回。
- `localStorage` 的 key 全部以 `abyss` 開頭，匯出檔含全部進度。
